# mittaltushant.github.io
Personal webpage of Tushant Mittal

Icons use a local copy of [Font Awesome Free 7.3.1](https://github.com/FortAwesome/Font-Awesome/releases/tag/7.3.1) in `assets/fontawesome/`. Load `assets/fontawesome/css/all.min.css` once per page. Use `fa-brands fa-google-scholar` for Google Scholar, `fa-brands` for other logos, and `fa-solid` or `fa-regular` for general icons. Academicons supplies DBLP, arXiv, and open-access icons.

To update Font Awesome, replace the stylesheet, all four webfonts, and `LICENSE.txt` together from the same `@fortawesome/fontawesome-free` release. The vendored files are unmodified; no build step or CDN is required.
